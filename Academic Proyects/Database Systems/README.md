## Overview

This project involves the design and implementation of a complete database solution across two distinct phases:

**Phase 1: OLTP (Operational Database)**
- Normalized relational data model design
- Schema implementation based on functional requirements
- Transaction-focused database architecture for operational efficiency

**Phase 2: OLAP (Data Warehouse)**
- Dimensional modeling using a star schema
- Fact and dimension table design
- Business metrics aggregation for analytical reporting

### Key Deliverables

- Relational schema with proper normalization (3NF)
- Views for simplified data access
- Stored procedures for business logic encapsulation
- User-defined functions for custom calculations
- ETL (Extract, Transform, Load) pipelines for data migration
- Analytical queries and business intelligence reports

### Technologies

- **Database:** Microsoft SQL Server
- **Design & Modeling:** ER diagrams, dimensional modeling
- **Concepts:** relational normalization, star schema, ETL processes

## Key Features

**Data Integrity & Performance:**
- Normalized schema design to eliminate data redundancy
- Indexes and query optimization for operational queries
- Efficient dimensional model for rapid analytical queries

**Automation & Maintenance:**
- Stored procedures for recurring business operations
- User-defined functions for complex calculations
- ETL pipelines for consistent data integration and transformation
