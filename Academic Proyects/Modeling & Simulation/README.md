## Overview

This project involves exploratory data analysis (EDA) on large datasets to identify and fit continuous probability distributions. The fitted distributions serve as stochastic input parameters for a discrete-event simulation model, designed and executed in Google Colab.

### Key Components

**Data Analysis Phase:**
- Exploratory data analysis using Pandas and Matplotlib
- Probability distribution fitting and evaluation with Fitter
- Statistical validation of fitted distributions

**Simulation Phase:**
- Discrete-event simulation model design
- Stochastic parameter integration from fitted distributions
- Results analysis and reporting

### Technologies

- **Languages:** Python
- **Libraries:** Pandas, Matplotlib, Fitter
- **Platform:** Google Colab

## Getting Started

All analysis and simulations are executed within Google Colab notebooks hosted in the project Drive. No local setup is required — simply open the notebooks and run the cells sequentially.
