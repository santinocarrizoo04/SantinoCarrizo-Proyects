## Overview

This project consists of two team assignments exploring advanced programming paradigms and techniques:

**TP1: Extensible Domain Framework in Ruby**
- Metaprogramming techniques for dynamic code generation and behavior modification
- Mixin composition for flexible code reuse across inheritance hierarchies
- Custom DSL (Domain-Specific Language) design for domain modeling
- Reflection and introspection for runtime type manipulation

**TP2: Hybrid Object-Oriented & Functional Programming in Scala**
- Object-oriented design patterns for domain logic structure
- Functional programming principles (immutability, pure functions, higher-order functions)
- Monadic and functional composition patterns
- Type system leverage for compile-time correctness guarantees

### Key Concepts

- **Metaprogramming:** Dynamic class/method generation, reflection, method_missing patterns
- **Mixins:** Multiple inheritance simulation, code reuse through trait composition
- **Functional Programming:** First-class functions, immutability, function composition, monads
- **Type Safety:** Scala's static type system and pattern matching capabilities
- **Domain-Driven Design:** Expressing business logic through expressive language constructs

### Technologies

**TP1:**
- **Language:** Ruby
- **Concepts:** Metaprogramming, mixins, DSL design, reflection

**TP2:**
- **Language:** Scala
- **Concepts:** Object-Oriented + Functional paradigms, type safety, pattern matching, monadic operations

## Learning Outcomes

These projects demonstrate practical mastery of:
- Writing clean, maintainable code that leverages language-specific advanced features
- Designing extensible systems through metaprogramming and composition
- Balancing object-oriented structure with functional programming principles
- Thinking about types and correctness at the language level
