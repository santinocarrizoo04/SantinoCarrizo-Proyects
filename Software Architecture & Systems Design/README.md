## My Contributions

I focused my work on two core modules within the system:

**Módulo-Colaboradores:**  
Full-stack development of a RESTful API that serves as a microservice within the broader distributed system architecture. This module is consumed by other system components and manages contributor-related business logic and data persistence.

**Módulo-Bot:**  
Design and implementation of a Telegram bot client that integrates with the Telegram Bot API to expose system functionality across a multi-platform messaging interface. The bot consumes the Contributors API and other system services to deliver real-time user interactions.
